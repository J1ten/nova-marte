Contexto do Projeto

Você foi contratado como estagiário de dados numa empresa fictícia chamada NovaMart, uma rede de varejo com lojas em 5 regiões do Brasil. O gestor pediu um relatório mensal de vendas e você vai construir todo o pipeline do zero:

01
Etapa 1 — Geração de Dados com Python
Python

Crie um arquivo chamado gerar_dados.py. Ele vai gerar 500 registros de venda falsos e salvar no banco SQLite novamart.db.

📦 Instale as dependências antes:
pip install faker pandas
gerar_dados.py
import sqlite3
import pandas as pd
from faker import Faker
import random
from datetime import date

fake = Faker('pt_BR')
random.seed(42)

# --- Dados fixos de referência ---
regioes = ['Norte', 'Nordeste', 'Centro-Oeste', 'Sudeste', 'Sul']
categorias = ['Eletrônicos', 'Roupas', 'Alimentos', 'Móveis', 'Esportes']

# --- Gerar tabela de vendas ---
registros = []
for i in range(500):
    registros.append({
        'id_venda':   i + 1,
        'data_venda': fake.date_between(
                         start_date=date(2024, 1, 1),
                         end_date=date(2024, 12, 31)
                      ),
        'regiao':     random.choice(regioes),
        'categoria':  random.choice(categorias),
        'vendedor':   fake.name(),
        'valor':      round(random.uniform(50, 5000), 2),
        'quantidade': random.randint(1, 20),
    })

df = pd.DataFrame(registros)

# --- Salvar no SQLite ---
conn = sqlite3.connect('novamart.db')
df.to_sql('vendas', conn,
           if_exists='replace', index=False)
conn.close()

print(f"✅ {len(df)} registros salvos em novamart.db")
print(df.head())

Tarefas desta etapa:

  • Rode o script e confirme que o arquivo novamart.db foi criado.
  • Adicione uma coluna ticket_medio calculada como valor / quantidade.
  • [Desafio] Crie uma segunda tabela chamada metas com meta de R$ 50.000 por região por mês e salve também no banco.
02
Etapa 2 — Análise com SQL
SQL · SQLite

Com o banco criado, use qualquer cliente SQL (DB Browser for SQLite, DBeaver ou o próprio Python) para executar as queries abaixo. Entenda o que cada uma retorna.

Schema da tabela vendas:

ColunaTipoDescrição
id_vendaINTEGERChave primária
data_vendaTEXTData no formato YYYY-MM-DD
regiaoTEXTUma das 5 regiões do Brasil
categoriaTEXTCategoria do produto
vendedorTEXTNome do vendedor
valorREALValor total da venda
quantidadeINTEGERQuantidade de itens
Query 1 — Total de vendas por região
SELECT
    regiao,
    COUNT(*) AS qtd_vendas,
    ROUND(SUM(valor), 2) AS total_vendas
FROM vendas
GROUP BY regiao
ORDER BY total_vendas DESC;
Query 2 — Ranking de categorias por receita
SELECT
    categoria,
    ROUND(AVG(valor), 2) AS ticket_medio,
    SUM(quantidade)       AS itens_vendidos
FROM vendas
GROUP BY categoria
ORDER BY ticket_medio DESC;
Query 3 — Evolução mensal de vendas
SELECT
    STRFTIME('%Y-%m', data_venda) AS mes,
    ROUND(SUM(valor), 2)           AS receita_mensal
FROM vendas
GROUP BY mes
ORDER BY mes;

Tarefas desta etapa:

  • Execute as 3 queries e copie os resultados para um arquivo resultados.txt.
  • Escreva uma query que mostre o Top 5 vendedores com maior receita total.
  • [Desafio] Escreva uma query que calcule o mês com maior crescimento percentual de receita em relação ao mês anterior (use LAG()).

Etapa 3 — Dashboard no Power BI
Power BI

Agora conecte o Power BI Desktop ao seu banco novamart.db e monte o dashboard.

1
Conectar ao SQLite: Obter Dados → ODBC → DSN ou string de conexão apontando para o arquivo novamart.db. Se necessário, instale o driver SQLite ODBC Driver (gratuito).
2
Criar coluna calculada no Power Query: adicione Ticket Médio = [valor] / [quantidade] direto no editor.
3
Criar medidas DAX:
Total Receita = SUM(vendas[valor])
Qtd Vendas = COUNTROWS(vendas)
Ticket Médio = DIVIDE([Total Receita], [Qtd Vendas])
4
Montar os visuais obrigatórios:
  • 3 Cartões: Total Receita, Qtd Vendas, Ticket Médio
  • Gráfico de barras: Receita por Região
  • Gráfico de linhas: Evolução mensal
  • Gráfico de pizza: Receita por Categoria
  • Tabela: Top 10 Vendedores
5
Adicionar um slicer (filtro): por Região e por Categoria para tornar o dashboard interativo.
💡 Alternativa ao ODBC: Se tiver dificuldade com a conexão SQLite no Power BI, você pode exportar os dados com Python usando df.to_csv('vendas.csv') e conectar via CSV. O aprendizado de SQL e Python continua válido!
