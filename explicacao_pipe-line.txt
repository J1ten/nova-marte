Explicação do arquivo pipe-line.py

Este arquivo gera dados falsos de vendas e salva em um banco de dados SQLite. Vou explicar cada parte como se você nunca tivesse visto Python.

1) Importações

import sqlite3
import pandas as pd
from faker import Faker
import random
from datetime import date

- import sqlite3: traz para o código a capacidade de trabalhar com banco de dados SQLite.
- import pandas as pd: traz a biblioteca pandas e dá a ela o apelido "pd". pandas é usada para trabalhar com tabelas de dados.
- from faker import Faker: traz a classe Faker da biblioteca faker, que gera dados falsos.
- import random: traz funções para gerar números aleatórios.
- from datetime import date: traz a função date para criar datas.

2) Criação de objetos e configuração

fake = Faker('pt_BR')
random.seed(42)

- fake = Faker('pt_BR'): cria um gerador de dados falsos com formato brasileiro (nomes e datas em português do Brasil).
- random.seed(42): define uma "semente" para o gerador aleatório. Assim, sempre que executar o código, ele gera os mesmos valores. Isso é útil para teste e repetição.

3) Listas fixas de referências

regioes = ['Norte', 'Nordeste', 'Centro-Oeste', 'Sudeste', 'Sul']
categorias = ['Eletrônicos', 'Roupas', 'Alimentos', 'Móveis', 'Esportes']

- Estas são listas de valores possíveis para as regiões e categorias de venda.
- O Python usa colchetes [] para criar listas. Exemplo: [1, 2, 3].
- Uma lista é uma sequência de valores que podem ser acessados e usados depois.

4) Preparar a lista de registros

registros = []
for i in range(500):
    valor = round(random.uniform(50, 5000), 2)
    quantidade = random.randint(1, 20)

    registros.append({
        'id_venda':   i + 1,
        'data_venda': fake.date_between(
                         start_date=date(2024, 1, 1),
                         end_date=date(2024, 12, 31)
                      ),
        'regiao':     random.choice(regioes),
        'categoria':  random.choice(categorias),
        'vendedor':   fake.name(),
        'valor':      valor,
        'quantidade': quantidade,
        'ticket_medio': valor / quantidade
    })

Explicando: 
- registros = []: aqui criamos uma lista vazia chamada registros. Essa lista vai receber cada venda.
- for i in range(500):: isso faz o Python repetir o bloco de código 500 vezes. A cada repetição, i recebe um número de 0 a 499.
- valor = round(random.uniform(50, 5000), 2): gera um número aleatório entre 50 e 5000 e arredonda para 2 casas decimais.
- quantidade = random.randint(1, 20): gera um número inteiro aleatório entre 1 e 20.
- registros.append({...}): adiciona um novo item à lista registros. Cada item é um dicionário.

O dicionário dentro do append tem pares chave: valor, por exemplo:
- 'id_venda': i + 1 -> número sequencial da venda.
- 'data_venda': fake.date_between(...) -> data aleatória entre 1° de janeiro e 31 de dezembro de 2024.
- 'regiao': random.choice(regioes) -> escolhe uma região da lista regioes.
- 'categoria': random.choice(categorias) -> escolhe uma categoria da lista categorias.
- 'vendedor': fake.name() -> nome falso do vendedor.
- 'valor': valor -> valor da venda gerado antes.
- 'quantidade': quantidade -> quantidade de itens gerada antes.
- 'ticket_medio': valor / quantidade -> calcula o ticket médio dividindo o valor pela quantidade.

Importante: a variável valor e a variável quantidade precisam existir antes de usá-las em ticket_medio. É por isso que criamos primeiro:
    valor = ...
    quantidade = ...

Se você escrever ticket_medio antes de criar essas variáveis, o Python dá erro.

5) Transformar em DataFrame

df = pd.DataFrame(registros)

- Aqui criamos um DataFrame do pandas a partir da lista de registros.
- Um DataFrame é como uma tabela, parecida com uma planilha do Excel.
- df é apenas o nome da variável. É comum usar df para indicar que o objeto é um DataFrame.
- Você poderia usar outro nome, por exemplo: vendas_df = pd.DataFrame(registros)

Por que usamos df = [] e não df = ()?
- [] cria uma lista.
- () cria uma tupla.
- Para construir uma lista de registros que vamos aumentar com append(), devemos usar [] porque listas são mutáveis (podemos adicionar itens).
- Tuplas são imutáveis, ou seja, não podemos usar append() nelas.

6) Salvar no banco SQLite

conn = sqlite3.connect('novamart.db')
df.to_sql('vendas', conn,
           if_exists='replace', index=False)
conn.close()

- conn = sqlite3.connect('novamart.db'): abre ou cria o arquivo de banco de dados chamado novamart.db.
- df.to_sql('vendas', conn, if_exists='replace', index=False): salva a tabela no banco com o nome vendas.
  - if_exists='replace' significa que, se já existir uma tabela vendas, ela será substituída.
  - index=False significa que não queremos salvar o índice numérico do DataFrame como coluna no banco.
- conn.close(): fecha a conexão com o banco.

7) Mensagem no final

print(f"✅ {len(df)} registros salvos em novamart.db")
print(df.head())

- print(...) escreve texto na tela.
- len(df) conta quantas linhas o DataFrame tem. Como geramos 500 registros, o resultado é 500.
- df.head() mostra as primeiras 5 linhas da tabela.

Resumo geral do fluxo

1) importar bibliotecas necessárias
2) configurar geradores de dados
3) criar listas de opções fixas
4) criar uma lista vazia de registros
5) preencher essa lista com 500 vendas falsas
6) criar um DataFrame pandas dessa lista
7) salvar o DataFrame em um banco SQLite
8) mostrar uma mensagem de confirmação

Como se você nunca tivesse visto Python

- Variável: nome que guarda um valor, como df, valor, quantidade.
- Lista []: coleção ordenada de itens. Exemplo: [1, 2, 3].
- Dicionário {}: grupo de pares chave: valor. Exemplo: {'nome': 'João', 'idade': 20}.
- Função: comando que faz algo. Exemplo: print(), round(), random.choice().
- laço for: repete um trecho de código várias vezes.

Perguntas comuns

- Por que usamos pandas? Porque facilita trabalhar com tabelas e salvar em bancos ou arquivos.
- Por que usamos Faker? Para gerar dados de exemplo automaticamente.
- O que é ticket médio? É o valor médio por item vendido, calculado como valor / quantidade.
- O que significa pd? É só um apelido para pandas. O código poderia usar outro apelido, mas pd é o padrão usado pela maioria dos programadores.
